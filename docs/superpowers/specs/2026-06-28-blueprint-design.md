# 图纸尺寸识别 - 设计文档

**日期**: 2026-06-28
**状态**: 已批准

---

## 概述

在封面制作工具中添加一个新的 Tab「图纸尺寸识别」，用于通过图片自动计算工程图纸的格子数量。

## 用户流程

1. **导入图片** → 用户上传或拖拽图片
2. **裁剪图纸** → 在原图上拖拽裁剪框，确定图纸区域
3. **选择格子** → 在裁剪区域内拖拽选择最小格子区域
4. **查看结果** → 显示图纸的格子数量

## 计算逻辑

```
裁剪后图纸像素尺寸 = 原图像素尺寸 × 裁剪比例
格子数量 = 裁剪后图纸像素尺寸 ÷ 格子框像素尺寸
```

**关键点**：所有尺寸计算基于原图像素尺寸，不受缩放影响。

## 技术方案

### 文件变更

| 操作 | 文件 | 说明 |
|------|------|------|
| 修改 | index.html | 添加 Tab 导航和图纸识别区域结构 |
| 修改 | styles.css | Tab 样式和图纸识别区域样式 |
| 新建 | blueprint.js | 图纸识别的核心逻辑 |

### 复用现有模式

- Tab 切换：通过 `hidden` 属性控制显示/隐藏
- 裁剪功能：复用现有 Canvas 裁剪交互
- 画框功能：类似裁剪的拖拽选择模式

### 组件结构

```
Tab 导航
├── 封面制作 Tab
│   └── 现有工作区
└── 图纸尺寸识别 Tab
    ├── 步骤指示器 (1-4)
    ├── 图片预览区 (Canvas)
    │   ├── 缩放控制
    │   ├── 裁剪框
    │   └── 格子框
    └── 结果展示区
```

## 交互细节

1. **缩放**：图片支持缩放查看，缩放不影响选择框尺寸
2. **格子框限制**：只能在裁剪区域内绘制
3. **可调整**：格子框绘制后可拖动调整位置和大小
4. **结果展示**：只显示格子数量（如 "10 x 15"）
