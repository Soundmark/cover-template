# 纯 HTML 封面模板设计文档

## 1. 背景

将现有的「封面制作」功能从图片模板方式重构为纯 HTML 构建方式。用户不再需要上传 PSD 模板图片，而是通过 HTML 结构直接生成封面，所有内容可编辑，最终可导出为 PNG 图片。

## 2. 整体布局

从上到下的垂直布局：

```
┌────────────────────────────────────┐
│         🧵 拼豆图纸分享            │  ← 固定标题
├────────────────────────────────────┤
│                                    │
│     [ 用户输入的图纸标题 ]          │  ← 用户可编辑
│                                    │
├────────────────────────────────────┤
│                                    │
│         ┌──────────────┐           │
│         │              │           │
│         │  图纸缩略图   │           │  ← 正方形，上传
│         │              │           │
│         └──────────────┘           │
│                                    │
├────────────────────────────────────┤
│       📐 图纸尺寸：__ × __         │  ← 用户输入
├────────────────────────────────────┤
│                                    │
│   [标签1] [标签2] [标签3] [+]      │  ← 用户输入标签
│                                    │
├────────────────────────────────────┤
│           🏠 拼豆屋                │  ← 固定
└────────────────────────────────────┘
```

## 3. 样式规格

### 画布
- 尺寸：1080 × 1440 px
- 背景色：#FFF8F0 (米黄色)

### 配色方案（暖色调温馨手绘风）
- 背景：#FFF8F0
- 主色调：#FF8C69 (珊瑚色)
- 辅助色：#FFB347 (暖橙色)
- 文字色：#5D4E37 (深棕色)
- 次要文字：#8B7355 (浅棕色)
- 装饰色：#FFEFD5 (奶油色)

### 字体
- 主字体：Ma Shan Zheng (Google Fonts 马上正楷，手写风)
- 备选：ZCOOL XiaoWei, Noto Sans SC

### 圆角
- 大圆角：24px
- 中圆角：16px

### 间距
- 区域间距：60px
- 内边距：80px

## 4. 各区域详情

### 4.1 拼豆图纸分享（固定）
- 字号：36px
- 颜色：#FF8C69
- 前缀图标：🧵
- 居中显示

### 4.2 图纸标题（用户输入）
- 字号：56px
- 颜色：#5D4E37
- 最大行数：2 行
- 自动换行，居中

### 4.3 图纸展示区域
- 形状：正方形
- 尺寸：600 × 600 px（占画布约 55%）
- 居中显示
- 圆角：24px
- 可上传图片，点击上传
- 图片填充方式：cover 模式（填满裁剪）

### 4.4 图纸尺寸
- 字号：32px
- 格式：「图纸尺寸：__ × __」
- 用户输入两个数字（宽 × 高）
- 颜色：#8B7355

### 4.5 图纸标签
- 用户手动输入，回车添加
- 标签样式：圆角矩形，#FFB347 背景
- 标签文字：#5D4E37
- 自动换行

### 4.6 拼豆屋（固定）
- 字号：28px
- 颜色：#8B7355
- 前缀图标：🏠
- 居中显示

## 5. 交互功能

### 编辑器界面
- 表单区域：用户输入标题、上传图片、输入尺寸、添加标签
- 实时预览：Canvas 渲染预览
- 导出按钮：生成 PNG 下载

### 输入验证
- 标题：必填，最大 50 字符
- 图片：支持 PNG/JPG，建议尺寸 800×800+
- 尺寸：数字，范围 1-500
- 标签：最多 6 个，每个最多 10 字符

## 6. 技术实现

### 导出机制
使用 html2canvas 或原生 Canvas API 将 HTML 结构渲染为图片：
1. 创建离屏 Canvas (1080×1440)
2. 按顺序绘制各区域内容
3. 导出为 PNG Blob
4. 触发下载

### 文件结构
```
index.html     → 模板结构 + 编辑器 UI
styles.css     → 编辑器样式 + 模板预览样式
app.js         → 编辑器逻辑 + 导出功能
```

## 7. 验收标准

- [ ] 封面可完整预览
- [ ] 所有内容可编辑
- [ ] 导出 PNG 图片清晰完整
- [ ] 暖色调温馨手绘风格一致
- [ ] 移动端适配良好
